# Lampa Rescue

Диагностическое расширение для Lampa, в первую очередь для проверки ошибок онлайн-воспроизведения на телевизорах LG webOS.

## Текущий статус

**Версия 0.1.0 — диагностическая, без автоматического переключения источников.**

Что делает:
- отслеживает запуск и закрытие плеера;
- фиксирует события готовности видео и ошибки плеера;
- при фатальной ошибке показывает короткую подсказку повторить запуск или выбрать другой источник/озвучку;
- сохраняет последние 30 событий локально в браузерном хранилище телевизора и выводит их в консоль.

Чего пока не делает:
- не переключает автоматически Z1, BWA, Онлайн Мод, Filmix или Showmy;
- не меняет качество, аудиодорожку или субтитры;
- не отправляет журналы на сервер.

## Установка

1. В Lampa открой **Настройки → Плагины → Добавить плагин**.
2. Вставь адрес скрипта:

   `https://raw.githubusercontent.com/melkiy189-max/lampa-rescue/main/lampa-rescue.js`

3. Подтверди добавление и перезапусти Lampa.

## Диагностика

При ошибке запиши название фильма/серии, выбранный источник и примерное время. Это поможет сопоставить проблему с событиями плеера.

Журнал хранится в localStorage под ключом `lampa_rescue_log_v1`. На телевизоре доступ к консоли может быть неудобен, поэтому для следующего этапа нужно будет добавить экран журнала прямо в интерфейс Lampa.

## Безопасность и приватность

Плагин не выполняет сетевых запросов, не загружает сторонний код, не меняет ссылки потоков и не отправляет данные наружу. Журнал остаётся в локальном хранилище браузера Lampa.
