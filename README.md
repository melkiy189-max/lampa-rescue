# Lampa Rescue

Проект собственного агрегатора источников для Lampa, с приоритетом совместимости с LG 42LF630V / webOS.

## Что хотим получить

Пользователь открывает карточку фильма или сериала, запускает Lampa Rescue и получает один общий список реально найденных вариантов от подключённых провайдеров. Внутри списка можно выбрать источник, озвучку и вариант воспроизведения, а затем вернуться и переключиться на другой.

## Текущие файлы и статус

- `lampa-rescue.js` — прежний диагностический прототип 0.1.0. Его короткая ссылка продолжает указывать на этот файл; поведение не изменено.
- `lampa-rescue-core.js` — прототип ядра агрегатора 0.2.0-core: экран источников, параллельный поиск зарегистрированных адаптеров, нормализация результатов, тайм-ауты и передача выбранного варианта плееру.
- `lampa-rescue-filmix.js` — экспериментальный адаптер Filmix: поиск фильмов, извлечение вариантов качества и озвучки. Сериалы пока не поддерживаются. Прокси по умолчанию отключён; требуется явно настроенный и доверенный прокси.
- `lampa-rescue-host-test.js` — отдельный экспериментальный экран проверки встроенных плееров RUTUBE и VK Видео. Не изменяет ядро и не является источником поиска фильмов.
- `lampa-rescue-experimental-bundle.js` — объединённый экспериментальный файл; НЕ содержит тестовый экран RUTUBE/VK и не является готовой установочной сборкой.
- `RESEARCH.md` — первичный анализ открытых решений, их зависимостей и архитектуры.
- `LAMPAC-INTEGRATION.md` — контракт LordFilm в Lampac и план безопасного подключения без публичных прокси.

**Важно:** проект пока не готов к установке как стабильная версия на телевизор. Экран RUTUBE/VK — только тест совместимости iframe-плееров; он не доказывает, что поиск по названию работает или что встроенное видео поддерживается старым webOS. Filmix также остаётся экспериментальным. Не используй неизвестный публичный прокси: он может видеть токен Filmix. Список источников не заполняется демонстрационными или выдуманными результатами.

## Тест RUTUBE / VK Видео

Исходник отдельного тестового плагина:
https://raw.githubusercontent.com/melkiy189-max/lampa-rescue/main/lampa-rescue-host-test.js

Он добавляет в карточку фильма кнопку «Тест RUTUBE / VK». В тестовом экране нужно вставить ссылку на публичное видео:
- RUTUBE: ссылка вида `https://rutube.ru/video/ID/` или `https://rutube.ru/play/embed/ID`.
- VK Видео: пока нужна именно ссылка встраивания `video_ext.php` с параметрами `oid`, `id` и `hash`; обычная ссылка на ролик не преобразуется автоматически.

Плагин принимает только известные домены и формирует адрес встроенного плеера сам. Видео может не открыться из-за ограничений встраивания самого ролика, сети или старого WebView телевизора. Результат нужно проверить на целевом устройстве. Пока не подключай тестовый файл в основную установку, пока отдельно не договоримся о тестовом способе загрузки.

Объединённый экспериментальный файл (только для разработки, не устанавливать как стабильную версию):

Рабочий файл ядра для просмотра:
https://github.com/melkiy189-max/lampa-rescue/blob/main/lampa-rescue-core.js

Прямая raw-ссылка на ядро (пока для разработки и тестов, не замена старой установочной ссылки):
https://raw.githubusercontent.com/melkiy189-max/lampa-rescue/main/lampa-rescue-core.js

Контракт провайдера описан в комментарии в ядре. Каждый адаптер регистрируется через `window.LampaRescue.registerProvider({ id, name, search })`; метод `search(movie, done)` возвращает реальные варианты или вызывает callback с ошибкой. Неуспешный/пустой ответ не превращается в фиктивный источник.

## Принципы

- Старый WebView: ES5-совместимый JavaScript и штатные API Lampa, насколько возможно.
- Изоляция провайдеров: ошибка одного источника не должна останавливать остальные.
- Никаких фальшивых результатов и фальшивых статусов доступности.
- Не загружать скрытый JavaScript с неизвестных адресов и не использовать `eval()` для динамического кода.
- Не копировать чужие исходники без проверки лицензии.
- Не передавать токены и учётные данные сторонним серверам без необходимости и ясного понимания протокола.
