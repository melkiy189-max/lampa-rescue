# Lampa Rescue

Проект собственного агрегатора источников для Lampa, с приоритетом совместимости с LG 42LF630V / webOS.

## Что хотим получить

Пользователь открывает карточку фильма или сериала, запускает Lampa Rescue и получает один общий список реально найденных вариантов от подключённых провайдеров. Внутри списка можно выбрать источник, озвучку и вариант воспроизведения, а затем вернуться и переключиться на другой.

## Текущие файлы и статус

- `lampa-rescue.js` — прежний диагностический прототип 0.1.0. Его короткая ссылка продолжает указывать на этот файл; поведение не изменено.
- `lampa-rescue-core.js` — прототип ядра агрегатора 0.2.0-core: экран источников, параллельный поиск зарегистрированных адаптеров, нормализация результатов, тайм-ауты и передача выбранного варианта плееру.
- `lampa-rescue-filmix.js` — экспериментальный адаптер Filmix: поиск фильмов, извлечение вариантов качества и озвучки. Сериалы пока не поддерживаются. Прокси по умолчанию отключён; требуется явно настроенный и доверенный прокси.
- `lampa-rescue-experimental-bundle.js` — объединённый файл ядра и адаптера для будущих тестов; не считать готовой установочной сборкой.
- `RESEARCH.md` — первичный анализ десяти открытых решений, их зависимостей и архитектуры.
- `LAMPAC-INTEGRATION.md` — проверенный контракт LordFilm в Lampac и план безопасного подключения без публичных прокси.

**Важно:** проект пока не готов к установке на телевизор. Filmix — экспериментальный адаптер, а не подтверждённый рабочий источник. Требуется проверить доступность API, прокси/CORS и запуск потоков на реальном webOS. Не используй неизвестный публичный прокси: он может видеть токен Filmix. Список не заполнен демонстрационными или выдуманными результатами.

Контракт провайдера описан в комментарии в начале/внутри ядра. Каждый адаптер должен регистрироваться через `window.LampaRescue.registerProvider({ id, name, search })`; метод `search(movie, done)` возвращает реальные варианты или вызывает callback с ошибкой. Неуспешный/пустой ответ не превращается в фиктивный источник.

## Принципы

- Старый WebView: ES5-совместимый JavaScript и штатные API Lampa, насколько возможно.
- Изоляция провайдеров: ошибка одного источника не должна останавливать остальные.
- Никаких фальшивых результатов и фальшивых статусов доступности.
- Не загружать скрытый JavaScript с неизвестных адресов и не использовать `eval()` для динамического кода.
- Не копировать чужие исходники без проверки лицензии.
- Не передавать токены и учётные данные сторонним серверам без необходимости и ясного понимания протокола.
